Документация проекта

О платформе

GamePlatform - это веб-платформа для классических игр, разработанная в рамках дипломного проекта. Платформа включает в себя три игры, систему статистики, профили пользователей и социальные функции.

Технологии

  • Backend: Python Flask
  • База данных: MySQL
  • Frontend: HTML, CSS, JavaScript, Bootstrap 5
  • Аутентификация: Flask-Login
  • Формы: Flask-WTF

Игры

Судоку

Классическая головоломка с числами. Доступны два размера поля:

  • 4x4 - легкий уровень
  • 6x6 - сложный уровень

Управление: Ввод цифр с клавиатуры

Система очков: 10 очков за каждую правильную клетку

Динозаврик

Бесконечный раннер, вдохновленный игрой из Chrome.

Управление: Пробел - прыжок

Система очков: 10 очков за каждое преодоленное препятствие

Тетрис

Игра-головоломка.

Управление:

  • ← → - движение
  • ↓ - ускорить падение
  • ↑ - повернуть фигуру

Система очков: 100 очков за линию

Уровни: Уровень повышается каждые 500 очков, скорость растет

Система статистики

  • Серии заходов: За каждый день входа серия увеличивается
  • Рекорды: Сохраняются лучшие результаты по каждой игре
  • Общая статистика: Количество игр, средний счет

Социальные функции

  • Друзья: Добавление пользователей в друзья
  • Комментарии: Возможность оставлять комментарии на стенах
  • Роли: Пользователи и администраторы

Разработчик

Проект разработан в рамках дипломной работы.
