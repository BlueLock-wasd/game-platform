# 🎮 GamePlatform — Игровой портал на Flask

Современная веб-платформа с тремя классическими играми, системой рейтинга, авторизацией и админ-панелью с графиками.

## 🚀 Технологии

- **Backend**: Python, Flask, Flask-Login, SQLAlchemy
- **База данных**: MySQL
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Графики**: Chart.js
- **Стиль**: Glassmorphism (стеклянный дизайн)

## 🎮 Игры

| Игра | Описание |
|------|----------|
| **Судоку** | Классическая головоломка. Доступны два размера: 4x4 (легкий) и 6x6 (сложный) |
| **Динозаврик** | Бесконечный раннер. Прыгай через кактусы и бей рекорды |
| **Тетрис** | Легендарная головоломка. Собирай линии, скорость растёт с каждым уровнем |

## 👥 Возможности

- ✅ Регистрация и авторизация с хешированием паролей
- ✅ Разделение ролей: **пользователь** и **администратор**
- ✅ Система рейтингов (сохранение лучших результатов)
- ✅ Серии заходов (streak) — поощрение за ежедневные входы
- ✅ Админ-панель с графиками популярности игр и топ-игроков
- ✅ Заметки на стене пользователя
- ✅ Загрузка аватаров
- ✅ Документация проекта (страница `/docs`)

## 🔧 Установка и запуск (локально)

### 1. Клонировать репозиторий
```bash
git clone https://github.com/BlueLock-wasd/game-platform.git
cd game-platform

### 2. Установить зависимости
pip install -r requirements.txt

### 3. Настроить базу данных MySQL
- Создайте базу `game_platform`
- Проверьте `config.py`

### 4. Инициализировать БД
python init_db.py

### 5. Запустить приложение
python app.py

Откройте `http://127.0.0.1:5000`
